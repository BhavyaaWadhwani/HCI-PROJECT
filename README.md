# Human Computer Interaction - Design Challenge

This repository hosts the static site explaining the design process of our proposed solution for the Human Computer Interaction - Design Challenge.

> Challenge: Create something to help people address a problematic behaviour

We tried to tackle the problem of **students scrolling through their phones during work sessions, which disrupts their focus and productivity**.
